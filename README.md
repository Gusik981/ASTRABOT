# AstraGrief - Discord Ticket Bot 🎫

Профессиональный интерактивный тикет-бот для Discord сервера проекта **AstraGrief**, разработанный на Python (`discord.py` 2.x) с поддержкой компонентов Discord UI (выпадающие меню, модальные окна, постоянные кнопки) и выгрузкой HTML-транскриптов.

---

## 🌟 Возможности бота

- 📑 **Интерактивная панель выбора**: удобное выпадающее меню со всеми категориями обращений (Техническая помощь, Покупка/Донат, Заявка на Медиа, Вопрос к Администрации).
- 📝 **Модальные формы (Modals)**: пользователи заполняют форму с темой и подробностями прямо в клиенте Discord.
- ⚡ **Постоянные кнопки (Persistent Views)**: все меню и кнопки работают непрерывно 24/7 даже после перезагрузки бота.
- 📜 **HTML-транскрипты**: генерация веб-транскрипта переписки в тёмной теме Discord со всеми вложениями, временем и эмбедами при закрытии тикета.
- 🔒 **Архивация тикетов**: закрытые тикеты аккуратно переносятся в архивную категорию со снятием прав на отправку сообщений.
- 👥 **Управление доступом**: кнопки и слэш-команды для быстрого добавления/удаления пользователей.

---

## 🚀 Быстрый запуск

1. **Ссылка для добавления бота на сервер**:
   ```text
   https://discord.com/oauth2/authorize?client_id=1565095551450751016&permissions=8&scope=bot%20applications.commands
   ```

2. **Запуск бота на Windows**:
   Запустите файл `start_bot.bat` (он автоматически поддерживает работу бота и перезапускает его в случае необходимости).

3. **Отправка панели тикетов в канал**:
   - На сервере в нужном канале напишите слэш-команду:
     ```text
     /ticket-panel
     ```
   - Либо запустите скрипт автоматической отправки:
     ```bash
     python send_panel.py
     ```

---

## 📋 Слэш-команды

| Команда | Описание | Доступ |
|---|---|---|
| `/ticket-panel` | Отправить панель тикетов AstraGrief в текущий канал | Администраторы |
| `/ticket-add @пользователь` | Добавить пользователя в текущий тикет | Внутри тикета |
| `/ticket-remove @пользователь` | Исключить пользователя из текущего тикета | Внутри тикета |
| `/ticket-close` | Закрыть текущий тикет с генерацией транскрипта | Внутри тикета |
